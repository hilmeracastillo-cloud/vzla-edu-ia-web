# Carpeta de Recursos Multimedia y Descargas
Coloca aquí los archivos correspondientes a las opciones de interacción del lector:

1. `infografia-1-pagina.pdf` (o .png/.jpg) -> Infografía (1 página)
2. `presentacion-35-slides.pdf` -> Presentación sin audio (35 slides)
3. `video-resumen-7min.mp4` -> Video síntesis (7 minutos)
4. `resumen-ejecutivo-4-paginas.pdf` -> Resumen ejecutivo (4 páginas)
5. `documento-completo-100-paginas.pdf` -> Documento completo (~100 páginas en PDF)

La aplicación web detectará y abrirá/reproducirá automáticamente cada uno de estos archivos.
